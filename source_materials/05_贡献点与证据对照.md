# 05 · 三个贡献点 ↔ 我们手上的证据 ↔ 还缺什么

江老师定的三条贡献：

> (1) 用 autoresearch 类似这种 pipeline 训练模型的方式
> (2) 全维度的测评
> (3) 使用更加权威、精炼的数据并有效合成（对比很多量很大但质量无法保证的数据，我们的数据量没那么大但效果显著）

下面把每一条拆成「主张 → 已有证据 → 缺口」。**凡"缺口"栏非空的，写作时要么先补，要么把主张写弱一档。**

---

## 贡献点（1）：pipeline 式的自动化训练闭环

### 主张能立到什么程度

我们真正跑通并留有全程记录的闭环是这一条：

```
训练 → 全量实测 → 抽错题 → 按知识骨架自动归因 → 按权威裁定 → 分类补救 → 回灌数据 → 重训
```

跑了 **33 轮**（v4.2 → v7.9，`0728/` 留存 63 个版本文件），每轮的删改都有逐条台账。

### 已有证据

| 环节 | 证据 |
|---|---|
| 自动归因 | 744 道错题按知识骨架归因：**68 真缺口 / 454 已教但全错在辨析 / 222 未匹配** |
| 逐题处置 | v7.8 系列把 596 道闭集错题**逐题**定性，产出 396 张对比卡 |
| 权威裁定 | 143 道金标存疑登记在案；5 条药典级勘误 |
| 补救分类 | 缺口→补语料；辨析失败→写对比卡；金标错→写勘误 + 兼容式卡片 |
| 防自欺判据 | 判"金标错/口径不符/指标伪影"必须拿**与分数无关**的证据（权威文件、逐条内容核查、评分器源码），举不出就留在"模型知识缺失"类 |
| 效果 | v7.9 相对裸基座：11 集简均 +6.96；闭集逐题翻转全部改对多于改错（ED-B 净 +104、MSDD 净 +35） |

**最有分量的一条方法学发现**：判"已教仍错"的题不豁免、也不再补知识量 —— 缺的是**与误选项的分界**，加量无效。这是 pipeline 里"补救要分类"的直接依据。

### 缺口 / 要小心的地方

1. **"autoresearch / 自动化"这个词要控制力度。** 我们的闭环里，归因和闸门是自动的，**裁定与造卡有大量人在环**。写成"全自动 pipeline"会被审稿人抓。建议写法：*human-in-the-loop 的迭代式数据精炼闭环，其中去污、归因、质量闸完全自动化*。
2. **重训扰动税必须自曝**：闭集每次重训必有约 4.3% 的**无向**翻转，与改动量无关，翻转只发生在约 665 道"摇摆带"上。所以**判增益必须看有向性**（改对/改错的比），不能只看均分。这一条不写，"每轮都在涨"的叙事站不住。
3. **有一条负结果建议照写**：CHGD 的病机段结构从 19% 提到 67%（打平金标），F1 只 +0.012。**这条路到头了。**负结果反而增强 pipeline 的可信度。

## 贡献点（2）：全维度测评

### 主张能立到什么程度

这一条是三条里**证据最硬、最没有争议**的。

| 主张 | 证据 |
|---|---|
| 五维覆盖 | MTCMB 5 维 / 11 集 / 6,997 题全跑 |
| 横向可比 | **13 个模型 × 10 集**，冻结协议，同一台机、同一套解码参数 |
| 三档口径敏感度 | L0 / L1 / L2 同一份 raw 离线重算，**v7.9 三档全部第一**，L0 领先 9.09 |
| 口径带宽做成论据 | v7.9 带宽 +0.57、闭集带宽 0；Fu-TCM-27B +0.14 是全表最小 → 证明"带宽小"是共性不是我们特有 |
| 底座不解释领先 | Fu-TCM-27B（同代同规模 Qwen3.5-27B）60.21 < 我们**裸基座** 68.53 |
| 规模不解释领先 | Xinghe1.2-9B 63.38 打赢 Fu-TCM-27B 60.21；L0 下我们裸基座 62.91 低于 BianCang-14B 64.88 |
| 噪声底实测 | 重复题组内对照测得 0.3~1.4%，取 ±1.0% 作噪声带（**不是拍脑袋的 ±40/√n**） |
| 退化基线 | PR 的常数处方基线 0.4341 高于表内所有模型 → benchmark 构念效度问题 |
| 可复现 | 协议、题单 SHA-256、md5 全在 |

### 缺口

1. ~~13×10 逐格矩阵没有本地副本~~ → **2026-08-24 已闭合**，全部原始产物（188 MB）落在 `附件/MTCMB评测原始产物_A61/`。同时纠正：逐子集是 **胜 6 / 并列 2 / 负 2**（数值第一 8 集，其中 6 集超出噪声带）。
2. **SE-A 没进横评表**（基线侧没跑 LLM 评分），所以横评 10 集、纵向 11 集，两处题量不同，表注要写清。
3. **SE-A 的裁判是 Claude 不是官方的 GLM-4-Air** —— 只有我们 base 与 v7.9 两列之间的差可用。
4. **抽取桥接必须自曝**，且不能与官方排行榜并列。（好消息：三档口径这套设计正好把这个弱点转成了论据。）
5. **没有独立专家组。** 5 条药典勘误在拿到 3 位执业医师确认之前，只能写 "discrepancy"，**不能写 "correction"**。这是对标稿有、我们空的两块之一（另一块横向 baseline 已经补上了）。

> 补记：竞品分析报告（`竞品分析_ZhongYan_JBHI.md`，2026-08-19）里写"我们横向 baseline 0 个"——**那是横评实验之前写的，现在已经补到 13 个，那一行已过期**，引用时注意。

## 贡献点（3）：权威、精炼的数据 + 有效合成

### 主张能立到什么程度

**核心对照（这一段可以直接做成论文的一张表）：**

| | ZhongYan（IEEE JBHI，10 作者，国家重点研发） | **我们（v7.9）** |
|---|---|---|
| 训练阶段 | CPT + SFT + DPO + RAG/KG | **仅 SFT（LoRA）** |
| 预训练语料 | 3.9 B token / 11.1 GB | 无 CPT |
| SFT 语料 | **272,000+ 条 / 794 M token** | **135,797 条**（约一半） |
| SFT 语料**质控** | 全文**没有一句**质量闸描述：无去污、无重复度扫查、无模板退化扫查、无闭集标签普查、无金标核查 | 六通道泄漏闸全 0（+ 独立第二实现复核）、13 条质量判据、逐条来源回溯到册+行号 |
| 主结果 | 69.12 → 78.67（+9.55，对自家 base） | 67.58 → 74.53（+6.96）；横评 13 模型三档口径全部第一 |

**"量不大但效果显著"的具体支撑：**

- 数据量约为对方的一半，且**没有 CPT 阶段**
- 前三类来源（教材 55.67% + 习题集 18.15% + 药典 13.02%）**占 87%，质量由出版物本身背书**
- 合成部分不是"让模型自由发挥"：走「证据表 → 问法 → 硬闸」，**判废率 8.9%，废因逐条留档**
- 逐条来源回溯，未定只剩 **166 条（0.12%）**
- 版本轨迹里**每一次行数下降都是删除**（v5.5 一度降到 110,415），不是回滚

### 缺口 / 要小心的地方

1. **"效果显著"要挂在横评上，不要挂在与 ZhongYan 的分数对比上。** 两边 benchmark 不同（他们用未公开的 ZhongYiBench），+9.55 与 +6.96 **不可直接比**。可比的是"每条数据被检查过几遍"这件事。
2. **对 ZhongYan 的批评只写"未描述"，不写"没做"。** 他们全文没写质控，不等于没做。措辞要用 *not reported* 而非 *absent*。
3. **单一来源依赖要如实写**（用药安全 91% 压在药典、辨证辨病 67% 压在 TCM-SD）—— 这正好是 SE-A"毒性药剂量往大里错"的成因链，写出来反而显得归因扎实。
4. **医案语料被我们否掉了**（太脏），这也值得写一句：不是所有可得的语料都该用。

## 附：立论主线的一个建议

三个贡献点如果平铺，会显得是三件不相干的事。建议用一条主线串起来 —— 这条主线在既有的论文计划里已经成型：

> **A point lost is not a point wrong.（丢分不等于答错）**

benchmark 的误差是**双向**的：既有虚高（模型见过题 → 需要去污，对应贡献点 3 的泄漏闸），也有虚低（答对被判成错 → 需要分差归因，对应贡献点 1 的错题回路）。而要把这两个方向都量出来，必须有**全维度、多口径、带退化基线**的测评（贡献点 2）。

三条贡献于是变成一条链：**测得准 → 才归因得准 → 才知道该补什么数据 → 数据不用多。**

支撑这条主线的两个物证（都是我们独有的）：
- **虚高方向**：三次泄漏事故，尤其是"打乱症状顺序不是消除泄漏而是规避检测"这一条
- **虚低方向**：SE-A 的 5 条金标与药典对不上 —— 其中 id14（附子孕妇）金标写"禁用"而药典是"慎用"，**照错金标去训，分数还会涨**。这是"虚低更危险"的最强例子

引文锚：ZhongYan §V-C-4 亲口说错题重训收益有限，归因于 *ambiguous ground truth*，然后把解法留给未来工作 —— **他们一段话，我们一篇论文**。
