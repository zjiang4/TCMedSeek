# 01 · MTCMB 基准：各子集测什么、怎么打分、怎么引用

材料来源：`data/MTCMB-main/MTCMB-main/dataset_info/*.md`（官方逐集说明）+ `ReadMe_cn.md`（排行榜与维度定义）。本文件的每一行都可以回到那两份原文核对。

## 一、基准总览

MTCMB（Multi-task Traditional Chinese Medicine Benchmark）：**5 个评估维度 / 12 个子数据集 / 7,100 条样本**。

| 维度 | 子集 | 题量 |
|---|---|---:|
| 知识问答 Knowledge QA | TCM-ED-A、TCM-ED-B、TCM-FT | 6,100 |
| 语言理解 Language Understanding | TCMeEE、TCM-CHGD、TCM-LitData | 300 |
| 诊断推理 Diagnostic Reasoning | TCM-MSDD、TCM-Diagnosis | 300 |
| 处方推荐 Prescription Recommendation | TCM-PR、TCM-FRD | 300 |
| 安全评估 Safety Assessment | TCM-SE-A、TCM-SE-B | 100 |
| **合计** | **12** | **7,100** |

> 写作提示：这是这篇文章"全维度测评"这一贡献点的落脚处 —— 中医大模型的横评论文里，大多只报知识问答（选择题）一档，把语言理解 / 诊断推理 / 处方推荐 / 安全四档一起报的很少。

## 二、逐子集：测什么 · 数据从哪来 · 用什么指标

### 知识问答

**TCM-ED-A**（1,200 题）
- 测什么：五选一（A–E）选择题，覆盖 12 个临床学科，中医**中级主治医师**层次的理论知识、辨证思维与临床决策。
- 数据来源：国家中医中级主治医师资格考试官方题库（才识教育科技标准化题库）。
- 构建方式：按 12 个临床学科分层抽样，每学科恰好 100 题；题目与答案经**三名持证中医执业医师**审核校准。
- 指标：准确率 Accuracy。

**TCM-ED-B**（4,800 题）
- 测什么：单项选择题，考察 TCM 领域的**广博知识覆盖**。
- 数据来源：国家中医**执业医师**资格考试官方题库（同上），8 套完整标准化模拟卷 × 600 题。
- 构建方式：整卷纳入，经专家 panel 验证学术权威性与临床相关性。
- 指标：准确率 Accuracy。

**TCM-FT**（100 题）
- 测什么：开放式**专家级问答**，中医基础理论、诊断、方药、针灸及临床各科。
- 数据来源：《中医学问答题库》（胡熙明主编，中医古籍出版社，1988）。
- 构建方式：随机抽样后由 DeepSeek-R1 语义改写，抽取要点作参考答案（`points` 字段），专家交叉验证。
- 指标：BERTScore（模型输出与 `points` 的语义对齐，实例平均后缩放至百分制）。
- ⚠️ **我们没有跑这一集**：官方仓库缺该集的 prompt yaml，跑起来会中断整条链路。**论文里必须写明我们报的是 11/12 集**。

### 语言理解

**TCMeEE**（100 例）
- 测什么：从临床叙事文本中抽取结构化中医实体 —— 症状、体征、西医病名、中医病名、证型、病因病机、治法、方剂、药物。
- 数据来源：中医智库（zhongyigen.com）95% + 执业医师提交医案 5%。
- 构建方式：DeepSeek-R1 生成结构化参考答案，执业医师审核输入与输出。
- 指标：**BLEU、ROUGE-L、BERTScore 的算术平均**。

**TCM-CHGD**（100 例）
- 测什么：把中医**医患问诊对话**转成标准化病历（中医疾病诊断、证候诊断、辨证依据、治法、方剂、药物组成）。
- 数据来源：国家中医药管理局认证中心《中医执业助理/执业医师实践技能考试案例分析题库》。
- 构建方式：DeepSeek-R1 依官方病案摘要**逆向生成**模拟问诊对话作为输入，原始官方答案作为标准输出，执业医师审核。
- 指标：BLEU、ROUGE-L、BERTScore 的算术平均。

**TCM-LitData**（100 条）
- 测什么：中医专业**文献理解与抽取式问答**。答案是段落原文中的**连续片段**。
- 数据来源：阿里云天池「中医文献问题生成」数据集（dataId=86895），随机抽样 100 条，专家审核。
- 指标：ROUGE 与 BLEU 取平均。
- 注意：这是**抽取**任务不是自由生成，答案必须是原文精确子串 —— 这一点我们踩过坑，见 04 文件。

### 诊断推理

**TCM-MSDD**（100 例）
- 测什么：**多标签分类**。给病历汇总文本，同时预测中医**证型（10 类闭集）**与**疾病（4 类闭集）**。
  - 证型：气虚血瘀证、痰瘀互结证、气阴两虚证、气滞血瘀证、肝阳上亢证、阴虚阳亢证、痰热蕴结证、痰湿痹阻证、阳虚水停证、肝肾阴虚证
  - 疾病：胸痹心痛病、心衰病、眩晕病、心悸病
- 数据来源：CCL25-Eval 任务 9 子任务 1（阿里云天池 competition/532301），随机抽样 100 例，执业医师额外一轮审核。
- 指标：准确率 —— 对证型、疾病分别算标准标签命中比例取算术平均，再对全部样本平均，百分制。
- ⚠️ **打分器是纯召回**：全部标签都打印出来就能拿高分。引用这一集的绝对分要谨慎，见 02 文件的口径说明。

**TCM-Diagnosis**（200 例）
- 测什么：以术语规范化的临床表现为输入，输出疾病名称、**证素（病位/病性）**、证名。内外妇儿各 50 例。
- 数据来源：国家"十三五"规划教材《中医内科学》《中医外科学》《中医妇科学》《中医儿科学》（新世纪第四版）。
- 构建方式：持证中医执业医师标注，多轮专家审核。
- 指标：BLEU、ROUGE-L、BERTScore 的算术平均。

### 处方推荐

**TCM-PR**（100 例）
- 测什么：根据复杂临床信息推荐中药方剂，预测目标是**药物集合**。
- 数据来源：CCL25-Eval 任务 9 子任务 2（同上竞赛），临床专家修订审核。
- 指标：集合匹配 —— Jaccard、Precision、Recall、F1，另引入 **Size Agreement（S_agree）**衡量处方规模合理性。实例分 S_inst = Jaccard、F1、S_agree 的算术平均；数据集分 = 实例分平均（百分制向下取整）。
- ⚠️ **这一集有构念效度问题**：我们实测「不看病例、恒定输出同一张常数处方」的退化基线就能拿 0.4341，高于表内所有参评模型。**论文里若报 PR，必须同时报这个退化基线**，否则数字没有意义。

**TCM-FRD**（200 例）
- 测什么：与 Diagnosis 并行构建，据证候表现生成**治法 + 方剂名 + 药物组成**（不含剂量）。
- 数据来源：同 Diagnosis（十三五四大临床教材），内外妇儿各 50 例。
- 指标：BLEU、ROUGE-L、BERTScore 的算术平均。

### 安全评估

**TCM-SE-A**（50 题）
- 测什么：**填空题**。按临床情境输出药典规定的标准术语 —— 配伍禁忌药对、妊娠禁用药、毒性药材安全剂量。
- 数据来源：《中华人民共和国药典》2020 年版一部中毒性药材、配伍禁忌、妊娠禁忌的结构化记录。
- 构建方式：DeepSeek-R1 基于药典记录合成，执业医师格式化与审核。
- 指标：**GLM-4-Air-250414 作为评测模型**打分（官方特意选了非参评模型以避免自评偏差）。
- ⚠️ 我们没有 GLM key，这一集是**由 Claude 逐题打分**的。同一裁判、同一 rubric、同一份金标，所以**只有我们自己 base 与 v7.9 两列之间的差可用，绝对分不能与排行榜并列**。

**TCM-SE-B**（50 题）
- 测什么：选择题，从候选项中识别正确的用药或针灸安全结论。
- 数据来源：同 SE-A（药典 2020 版）。
- 指标：准确率 Accuracy。

## 三、我们实际跑的口径（论文 Methods 必须原样写进去）

| 项 | 取值 |
|---|---|
| 子集 | 生成 11 集（缺 TCM-FT），打分 10 集 + SE-A 自有裁判 |
| 实际题量 | **6,997 题**（7,100 − TCM-FT 100 − ED-A 中作为 few-shot 示例剔除的 3 题） |
| 提示策略 | `--prompt-type 1` = **few-shot**，对应官方排行榜的 "Few-Shot" 行 |
| 模型接入 | 自定义模型类 `qwen_tcm_b` 注册在 `make_answer/chat/__init__.py` 的 `name_model_dict` —— 这是**官方文档规定的扩展点** |
| 解码 | 贪婪 / repetition_penalty 1.05 / max_new_tokens 1024（nothink）· 2048（think） |
| 注意力实现 | sdpa |
| think 开关 | nothink（`TCM_THINKING` 关） |

### 四处与官方 ReadMe 的偏离 —— 论文里必须自曝

1. **抽取桥接（最要紧）**。`make_answer/works/_postprocess_bridge.py` 是我们新增的文件，接进 ED-A/ED-B/MSDD/Diagnosis/PR/FRD/SE-B 七个子集的读答案路径。官方原版拿模型原文直接进打分器 —— 模型答「【答案】：B」官方抓不到就判 0。**这会系统性抬分，我们的数与排行榜不是同一把尺子。**
   - 应对：横评时我们把同一份 raw 离线重算了三档口径（L0/L1/L2），把这个偏差量化成"口径带宽"。见 02 文件，这反而成了论文里最有力的一段。
2. **think/nothink 的定义不同**。官方 `--prompt-type 2` 是提示词层的 CoT；我们的 `TCM_THINKING` 是 Qwen chat template 的 `enable_thinking`，官方没有这个概念。
3. **少两个子集**：官方 12 个，我们生成 11、打分 10（+SE-A 自评）。
4. **解码参数固定**：官方未规定，我们固定了。

> 这四条已经写进 `deliver_v7_9/实测报告_v7_9.md` 的「六、口径纪律」一节，可直接译用。
